مخطط التوصيل الكهربائي (Wiring Diagram)

شكل 1 — توصيل درع البطارية 18650 V3 ← ESP32 DevKit V1 ← مجس رطوبة التربة السعوي V1.2

جدول التوصيلات (Pinout Table)

From Wire Color To Note
Battery Shield 5V Red ESP32 5V Main power supply
Battery Shield GND Black ESP32 GND Common ground
ESP32 3.3V Orange Sensor VCC 3.3 V logic — do not use 5 V
ESP32 GND Gray Sensor GND Sensor ground reference
ESP32 GPIO 32 Purple Sensor AOUT Analog signal (ADC1_CH4)
